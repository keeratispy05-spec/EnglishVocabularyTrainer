# VOCABORA

เว็บแอปฝึกคำศัพท์ภาษาอังกฤษสำหรับผู้เรียนชาวไทย พัฒนาด้วย Python และ Streamlit

## Features
- เรียนรู้และค้นหาคำศัพท์ภาษาอังกฤษ
- ฝึกด้วยบัตรคำศัพท์และแบบทดสอบ
- ติดตามผลการเรียนและทบทวนคำศัพท์

## Run locally
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

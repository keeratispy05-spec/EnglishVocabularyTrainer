# ข้อมูลคลังคำศัพท์ VOCABORA

- `vocabulary.json` คือชุดข้อมูลเริ่มต้นที่แยกจากโค้ดแอป มีคำศัพท์ไม่ซ้ำกัน 1,088 รายการ ครอบคลุม 40 หมวดหมู่ และระดับ A1–C2
- ทุกคำมีตัวอย่างประโยคภาษาอังกฤษและคำแปลภาษาไทยเพื่อฝึกใช้คำในบริบท ตัวอย่างจัดทำเพื่อการเรียนรู้ ไม่ใช่ชุดประโยคที่ผ่านการรับรองจากผู้จัดสอบ จึงควรตรวจทานก่อนนำไปใช้เป็นสื่อสอบอย่างเป็นทางการ
- ระดับ CEFR เป็นการจัดระดับโดยประมาณเพื่อช่วยเลือกคำฝึก ไม่ใช่การรับรองอย่างเป็นทางการจากผู้จัดสอบ
- ช่องคำอ่าน/IPA และคำพ้องความหมายอาจเว้นว่างได้เมื่อไม่มีข้อมูลที่เชื่อถือได้
- เพิ่มคำศัพท์ผ่านหน้าตั้งค่าในแอป โดยนำเข้า JSON หรือ CSV ตามไฟล์ตัวอย่าง ระบบจะข้ามคำศัพท์ที่ซ้ำและไม่ลบรายการเดิม
- เมื่อเปลี่ยนชุดข้อมูลตั้งต้น แอปจะเติมตัวอย่างและข้อมูลกำกับให้รายการเดิมเฉพาะช่องที่ยังว่าง โดยคงความหมาย ตัวอย่างเดิม และประวัติการเรียนไว้
- การนำเข้าข้อมูลจาก LEXiTRON หรือพจนานุกรมภายนอกควรตรวจสอบความถูกต้องของคอลัมน์คำศัพท์/คำแปล ตลอดจนเงื่อนไขสัญญาอนุญาตก่อนนำมาแจกจ่ายต่อ

แหล่งข้อมูลภายนอกสำหรับศึกษาเพิ่มเติม:
- LEXiTRON, ศูนย์เทคโนโลยีอิเล็กทรอนิกส์และคอมพิวเตอร์แห่งชาติ (NECTEC): https://lexitron.nectec.or.th/
- NECTEC Data Catalog: https://opend-portal.nectec.or.th/en/prepare/lexitron-2-0
